# csvstat

CSV 列级统计画像：文件进，每列一张"体检卡"。

纯 Python 标准库（`csv` / `argparse` / `statistics` / `json` / `collections`），无依赖，纯本地运行。

## 快速开始

```bash
python -m csvstat examples/sales.csv
python -m csvstat examples/sales.csv --column price # 只看某一列
python -m csvstat examples/sales.csv --json # 机器可读
python -m csvstat big.csv --sample 1000 # 大文件只采样前 1000 行
```

## 类型推断规则（诚实文档）

这是**启发式**，不是严格的类型系统：

1. 空值（空串/全空白）不参与判断；
2. 非空值中 ≥90% 能解析为整数 → `int`（千分位逗号会被去掉）；
3. 否则 ≥90% 能解析为浮点数 → `float`；
4. 否则 ≥90% 匹配常见日期格式 → `date`（支持 `YYYY-MM-DD`、`YYYY/MM/DD`、`MM/DD/YYYY`、ISO datetime）；
5. 否则 → `string`，置信度按"最像其他类型的占比"反推。

置信度 <90% 的列请人工复核——比如 `sale_date` 里混了 `2026/10/06` 和 `10/07/2026` 两种格式，
三种都被正则覆盖，置信度仍是 100%——但注意"最早/最晚"是字符串比较，
混杂格式下排序可能不符合日历顺序，这是已知取舍。

## 参数

| 参数 | 说明 |
|---|---|
| `file` | CSV 文件路径（UTF-8/带 BOM 均可） |
| `--column NAME` | 只输出某一列的详细统计 |
| `--json` | 输出 JSON |
| `--sample N` | 只读前 N 行（大文件画像用，默认全读） |

退出码：0 正常；1 文件空/无数据行/列名不存在；2 用法错误或读文件失败。

## 局限（已知取舍）

- 类型推断是启发式：`"001"` 会被判为 int（前导零信息丢失），这是已知取舍；
- 日期只认正则列出的几种格式，不做真实日历校验（`2026-13-99` 也会通过）；
- 整个文件读入内存，GB 级 CSV 请先用 `--sample`；
- 只做描述性统计，不做异常值判定——"离群"需要业务上下文，工具不替你下结论。
